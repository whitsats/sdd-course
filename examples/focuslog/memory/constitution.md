# focuslog 宪法

> **本文件是 L02 的完整参考产出。** 对照重点：每条原则都能被用作「code review 不给过」的理由。
> 自查方法：对每条问「我能构造一个违反它的具体例子吗？」——构造不出来就删掉。

**项目**：focuslog（本地优先的开发者专注日志 CLI）
**最后更新**：2026-09-22 ｜ **修订原因**：初始版本

---

## 1. 技术栈与版本

- 运行时 **Python 3.10+**，不使用低于 3.10 的语法特性
- 依赖管理用 **uv**；仓库中不提交 `requirements.txt`
- 生产依赖**仅允许 Typer**。任何新增生产依赖需在本文件中登记并说明理由

> 违反判据：`pyproject.toml` 的 `dependencies` 出现第 2 个包，且本文件未登记。

## 2. 架构边界

- 分层为 `cli/ → services/ → domain/` 与 `storage/`、`render/`
- **`domain/` 不得 import `storage/`、`render/`、`cli/`，且不得包含任何 IO 调用**（`open` / `Path` / `json` / `os`）
- `cli/` 不得直接调用 `storage/`
- `storage/` 不得包含业务规则

> 违反判据：`grep -rEn '\b(open|Path|json\.load|json\.dump|os\.)\b' src/focuslog/domain/` 有输出。此检查已进 CI。

## 3. 测试与质量门禁

- 所有公开函数必须有单元测试
- **`spec.md` 中每一条验收标准必须映射到至少一个测试用例**，映射关系记录在 `docs/验收标准-测试映射.md`
- 测试必须能在**无网络、无外部服务**环境下运行
- 时间相关测试**不得 mock 系统时钟**，必须通过注入 `Clock` 实现

> 违反判据：出现 `@patch('datetime.datetime')` 或 `freezegun`；映射表行数 ≠ spec 标准条数。

## 4. 安全与隐私

- 所有外部输入（命令行参数、存储文件内容）在进入 `domain/` 前必须经过校验
- 存储文件被用户手改损坏时，**不得静默重建或覆盖**，必须报错并保留原文件

> 违反判据：损坏 `sessions.json` 后执行任意命令，原文件内容发生变化。

## 5. 性能预算

- 任命令在 10000 条会话量级下的执行耗时 **P95 < 200ms**
- 存储单文件超过 **5 MB** 时必须在 README 中说明并重新评估存储方案

> 违反判据：本地跑基准脚本，P95 超过阈值。

## 6. 可观测性

- 所有错误输出必须包含**机器可读错误码**（`errors.py` 中集中定义）
- 退出码语义固定：**0** 成功 / **1** 参数错误 / **2** 运行期错误

> 违反判据：`errors.py` 之外出现硬编码的 `sys.exit(1)`；或新增错误码未登记在 `errors.py`。

## 7. 文档与提交

- **任何改变对外行为的变更（输出格式、退出码语义、错误码、存储 schema），必须同步更新 `spec.md` 中对应的验收标准**
- 存储 schema 变更必须递增 `schema_version` 并提供迁移路径
- 提交信息格式：`<type>: <描述>`，`type ∈ {feat, fix, refactor, docs, test, chore}`

> 违反判据：PR 改变了输出格式或退出码，但 diff 中不含 `spec.md`。

## 附：明确不在宪法范围

以下内容**不属于宪法**（属于 feature 规格），不应出现在本文件：

- 具体的功能行为（如「周报覆盖 ISO 周」）
- 单个 feature 的验收标准
- 临时性的实验约束
