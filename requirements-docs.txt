# 文档站点（GitHub Pages）的构建工具。
#
# 这不是本仓库的运行依赖 —— 只想读讲义、跑 examples/ 的人完全不需要它。
# zensical 是 CLI 工具，所以用 uvx 隔离运行，不往仓库里装 .venv：
#
#   python tools/build_site.py                                     # ① 拼装源文件
#   uvx --with-requirements requirements-docs.txt zensical serve   # ② 本地预览（默认 8000）
#   uvx --with-requirements requirements-docs.txt zensical build --strict --clean
#
# ⚠️ 国内镜像会 403 时怎么办：
#   本机构了清华源（pip.ini 里 global.index-url），但那个源当前对**所有**请求
#   返回 403（curl 根索引也是 403），于是 uvx 报的错很有误导性：
#     "zensical was not found in the package registry … An index URL … returned a 403"
#   —— 它像是在说「没有这个包」，实际是镜像挂了。官方源正常（HTTP 200）。
#   临时绕过（只对本次命令生效，不改你的全局配置）：
#     UV_DEFAULT_INDEX=https://pypi.org/simple uvx --with-requirements requirements-docs.txt …
#   CI 不受影响：GitHub runner 默认走官方源。
#
# CI 在推送到 main 时跑同样三步并部署到 Pages，见 .github/workflows/docs.yml。
#
# 为什么是 Zensical：它是 Material for MkDocs 的官方继任者（同一团队 squidfunk）。
# mkdocs-material 已定于 2026-11-05 EOL（9.7.0 为最后一版），底层 MkDocs 1.x 自
# 2024-08 起无人维护，且 MkDocs 2.0 明确「没有迁移路径」。
# Zensical 自带保持 Material 外观的 classic 主题变体，配置格式（TOML）见 zensical.toml。
